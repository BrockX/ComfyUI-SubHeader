# ComfyUI-SubHeader

Visual UI organization tools for ComfyUI subgraphs.

## Features

SubHeader provides three types of visual elements:

- Header
- Line
- Space

These elements are intended for organizing promoted parameters
when a node is displayed as a ComfyUI subgraph.

The elements do not participate in execution.

## Header

Headers support:

- Custom name
- Position
- Left / centered / right alignment
- Text color
- Background color

## Line

Lines support:

- Position
- Thickness
- Color

## Space

Spaces support:

- Position
- Height

## Frontend

Designed for ComfyUI frontend 1.48.7.

## Installation

Copy the `ComfyUI-SubHeader` folder into:

    ComfyUI/custom_nodes/

Restart ComfyUI.

The node appears under:

    Subgraph UI
